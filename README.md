# AksharaDeepa Tutor

AksharaDeepa is an educational Android app that promotes literacy, language learning, quizzes, and cultural values among children.

## Features
- Quiz Levels
- Progress Tracking
- Result Screen
- Educational Learning
- Simple UI Design
